## 小模型微调与部署的培训

需要从下面几个角度解释与讲解模型的微调:

### 1. 样本划分 (Data Partitioning)

在这个阶段, 海量的文本数据被准备好并切割成模型可以消化的"小块(Chunk)". 

- **Token 化 (Tokenization)**: 文本首先被切分成模型能看懂的词元(Token). 比如"我爱机器学习"可能被切分成 `[我, 爱, 机器, 学习]` 并转化为对应的数字 ID. 
- **构建输入与标签 (Inputs & Labels)**: 大模型通常采用"下一个词预测(Next-Token Prediction)"任务. 如果输入序列是 `[我, 爱, 机器]`, 那么它的真实标签(Ground Truth)就是 `[学习]`. 
- **批处理 (Batching)**: 模型不是看一句话训练一次, 而是同时看很多句话. 
  - **Global Batch Size**: 全局每一轮看多少数据. 比如设为 1024, 意味着训练一次要看 1024 条长句子. 
  - **Micro-Batch Size**: 在分布式训练中, 这 1024 条数据会被分发到各个 GPU/NPU 卡上, 单张卡一次处理的数据量就叫微批次(比如每张卡分到 4 条). 

### 2. 损失计算 (Loss Calculation / 前向传播)

这是模型做"预测"并评估"自己有多笨"的阶段. 

- **前向传播 (Forward Pass)**: 数据进入模型. 输入的 Token 经过多层 Transformer(包括自注意力层和全连接层)的复杂矩阵乘法, 最终在最后一层输出一个词表大小的概率分布. 
- **计算概率**: 模型会给词表里的每一个词打分. 比如预测下一个词是"学习"的概率为 20%, 是"苹果"的概率为 5%. 
- **计算损失 (Loss)**: 使用**交叉熵损失函数(Cross-Entropy Loss)**. 系统会将模型的预测概率与真实标签(100% 应该是"学习")进行对比. 预测越准, Loss 越小; 预测越离谱, Loss 越大. 最终得出一个标量数值, 代表模型当前表现的误差. 

### 3. 梯度计算 (Gradient Calculation / 反向传播)

算出误差后, 模型需要知道"究竟是哪个参数出了问题, 该往哪个方向改". 这个过程依靠微积分中的链式法则(Chain Rule), 这里通常需要使用矩阵微积分. 

- **反向传播 (Backward Pass)**: 计算过程从最后一层往回倒推, 回到第一层. 
- **求导数 (Gradients)**: 系统会对模型中的**每一个参数(权重 $W$)** 计算它对最终 Loss 的偏导数. 这个偏导数就是**梯度$(\nabla W)$**. 
- **梯度的物理意义**: 梯度就像是指南针. 它告诉我们, 如果想让当前的误差(Loss)变小, 这个特定的参数 $W$ 应该增大一点点还是减小一点点. 

### 4. 参数更新 (Parameter Update)

这是模型真正"变聪明"的时刻, 由优化器(Optimizer, 如 AdamW)主导. 

- **应用规则**: 优化器拿着刚刚算出的所有梯度, 决定最终要怎么修改参数. 
  - 如果你用的是最基础的 SGD, 公式大概是: `新参数 = 老参数 - (学习率 × 梯度)`. 
  - 在大模型中通常使用 AdamW 优化器(Adam with Decoupled Weight Decay), 它还会参考历史梯度(一阶动量和二阶方差), 防止参数更新过猛或陷入死胡同. 
- **更新权重**: 优化器在内存中把新的数值写入模型参数矩阵中. 至此, 模型完成了一次"学习". 
- **清空梯度 (Zero Grad)**: 更新完后, 必须把所有的梯度清零, 干干净净地迎接下一个批次的数据.
