## 阶段 1：NumPy 核心（15 分钟）

**目标**：理解 `ndarray` 不是“更快的 list”，而是「连续内存 + dtype + shape + strides」。

1. ndarray 的本质（5 分钟）
   - `dtype / shape / ndim / size / itemsize / nbytes / strides`
   - Python list（对象引用数组） vs ndarray（连续缓冲区）
   - 内存对比实验：约 64 MB vs 约 16 MB
2. axis 轴（4 分钟）
   - axis=0 / axis=1 / axis=-1 的折叠方向
   - 2D 求和、3D 多轴聚合各举一例
3. View / Copy / Strides（4 分钟）
   - 切片、转置返回 View（`base` 判断）
   - 花式索引、布尔索引返回 Copy
   - `as_strided` 零拷贝滑动窗口（只做演示）
4. Broadcasting 与 UFunc（2 分钟）
   - 靠右对齐 + 长度为 1 的扩展规则
   - `np.where` / `ufunc.at` 解决重复索引累加

> **这一节只讲“心智模型”，不展开全部 API。** 重点是让学生能解释为什么 NumPy 快。

## 阶段 2：Pandas 核心（38 分钟）

**目标**：把七个业务问题当成主线，边解决问题边引入 API。

### 2.1 Pandas 设计哲学（4 分钟）
- `Series = values + index`，`DataFrame = 多个 Series 的列式集合`
- 标签对齐：`s1 + s2` 自动按索引对齐，不匹配显式 NaN
- 一句话：NumPy 解决“怎么算”，Pandas 解决“怎么带着业务语义组织表”

### 2.2 Q1 数据可信度诊断（7 分钟）
- `dtype`、缺失值诊断、`mask`、`loc`、`query`
- `np.select` 把异常进一步分类
- 落到代码：读 parquet → 转 datetime → 构造 `trip_minutes` → 组合 mask → 产出 `clean_taxi`

### 2.3 Q2～Q4 聚合 / 回填 / 拼接（13 分钟）
- **Q2 一天中什么时候最忙**（4 分钟）
  - `datetime.dt.hour`、`groupby + agg`
- **Q3 单位运营时间收入最高**（4 分钟）
  - `assign` 构造派生指标、`transform` 回填组内均值
- **Q4 哪些上下车区域最热门**（5 分钟）
  - `value_counts`、`rename_axis + reset_index`、`merge + validate`
  - 用真实 `taxi_zone_lookup.csv` 拼出 Borough / Zone

### 2.4 Q5 时间窗口异常（8 分钟）
- `quantile`、`np.select` 单笔异常
- `transform` 贴回“所在小时”中位数 / p95
- `where` 只保留异常值
- `resample("1h")` + `rolling` + 3σ 动态阈值

### 2.5 Q6 为什么性能差一个数量级（6 分钟）
- 四种执行层：Python loop / `apply(axis=1)` / 向量化 / Numba
- 内存与存储：`dtype`、列裁剪、Parquet
- 强调：**公平对比必须让所有方案做完全相同的工作**

# 课堂作业

## 作业 1：数据清洗 + 小时聚合（Q1 + Q2 综合）

**目标**：练习 `dtype`、缺失值、`mask`、`query`、`groupby + agg`。

**题目**：
1. 读取 `yellow_tripdata_2025-12.parquet`，构造 `trip_minutes`；
2. 用 `mask` 定义“可信订单”规则（金额、距离、时长、区域 ID 均有效）；
3. 用 `query` 产出 `clean_taxi`，打印清洗前后的行数；
4. 按 `pickup_hour` 分组，输出：
   - `order_count`（订单数）
   - `total_revenue`（总流水）
   - `avg_total_amount`（平均客单价）

**提交**：一段可运行代码 + 一句话回答“哪个小时订单最多”。

**预计用时**：10～12 分钟（课堂练习或课后完成均可）。

---

## 作业 2：窗口异常检测 + 公平性能对比（Q5 + Q6 综合）

**目标**：练习 `resample`、`rolling`、以及“同工作量”的性能对比设计。

**题目**：
1. 在 `clean_taxi` 基础上构造 `revenue_per_minute`；
2. 用 `resample("1h")` 汇总每小时 `total_revenue`；
3. 用 `rolling` 计算 6 小时均值与标准差，并用 `mean + 3 * std` 标记疑似尖峰窗口；
4. 用课程里的 `benchmark` 工具，对比三种“计算 `revenue_per_minute`”的写法：
   - Python `for` 循环
   - `apply(axis=1)`
   - 向量化表达式

**提交**：一段可运行代码 + 一句话解释“为什么 `apply(axis=1)` 反而比纯 Python 循环慢”。

**预计用时**：12～15 分钟（课后完成）。
